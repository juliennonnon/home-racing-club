# Home Racing Club

Course de mini-voitures dans le salon, jouable dans le navigateur, en solo ou jusqu'à 8 joueurs en réseau.

- **Jouer** : https://juliennonnon.github.io/home-racing-club/
- **Multijoueur** : un joueur crée une partie et donne le code à 4 lettres aux autres.
- **Commandes** : flèches ou WASD, Espace pour déraper, R pour se replacer.

Tout le jeu tient dans `index.html` ; `lib/` contient Three.js et PeerJS.
